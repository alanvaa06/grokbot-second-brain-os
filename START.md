# START.md: instructions for agents

You are an agent and your owner gave you this repository. Do this, in order:

1. If you are reading this inside a vault whose `LOCAL.md` has a non-empty `initialized: YYYY-MM-DD` value, this vault is set up. Stop here and read `AGENTS.md` instead. Otherwise clone this repository into a temporary folder (the bootstrap copy; it is read-only and the init skill creates the real vault folder) and continue.
2. Read `agents/_skills/second-brain-init/SKILL.md` in full and follow it. It creates the owner's private repo from this template (or clones locally if there is no GitHub auth), interviews the owner one question at a time, registers projects and agents, applies the role blocks, and commits. If that file is missing, stop and tell the owner the clone is incomplete.
3. Do not improvise the setup. Do not skip questions. Do not create anything the owner did not confirm.

If you are a human reading this: paste this repo's URL to your chief-of-staff agent. `README.md` explains the rest.
